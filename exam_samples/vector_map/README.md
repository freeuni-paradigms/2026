# vector_map (ჯენერიკები - 60 ქულა)
თქვენი ამოცანაა იმპლემენტაცია გაუკეთოთ Map ჯენერიკ სტრუქტურას უკვე იმპლემენტირებული Vector-ის გამოყენებით.

<span style="color:red">**!!! არ გაქვთ უფლება Vector-ის ცვლადების პირდაპირ გამოყენების, უნდა გამოიყენოთ მხოლოდ ვექტორის მეთოდები. !!!**</span>

Map სტრუქტურას უნდა ქონდეს შემდეგი მეთოდები:

* void MapInit(Map* m, int key\_size, int value\_size, CmpFn key\_cmp\_fn, FreeFn key\_free\_fn, FreeFn value\_free\_fn) - ინიციალიზაცია უნდა გაუკეთოს გადმოცემულ მეპს, სადაც key\_size არის გასაღებების ზომა ბაიტებში, value\_size არის მნიშნველობების ზომა ბაიტებში, key\_cmp\_fn არის გასაღებების შემადარებელი ფუნქცია, key\_free\_fn და value\_free\_fn უნდა გამოიყენოთ გასაღებების და მნიშნველობების მეხსიერებების გასათავისუფლებლად.
* void MapDestroy(Map* m) - უნდა გაათავისუფლოს მეპის მიერ გამოყენებული მეხსიერება.
* void MapSet(Map* m, void* key, void* value) - მოცემულ გასაღებზე უნდა დაიმახსოვროს მოცემული მნიშვნელობა. მფლობელობას იღებს ორივე მისამართზე.
* void* MapGet(Map* m, void* key) - უნდა დააბრუნოს მოცემულ გასაღებზე შენახული მნიშვნელობის მისამართი.
* void MapRemove(Map* m, void* key) - მეპიდან უნდა ამოაგდოს მოცემული გასაღები და მასთან ასოცირებული მნიშვნელობა. თუ გასაღები მეპში არ გვხვდება მაშინ არაფერი არ უნდა შეიცვალოს მეპში.
* void MapMap(Map* m, MapMapFn map\_fn, void* aux) - მეპში შენახული ყოველი (key, value) წყვილებისთვის უნდა გამოიძახოს გადმოცემული map\_fn ფუნქცია და არგუმენტებად გადასცვეს მიმდინარე გასაღების მისამართი, მასთან ასოცირებული მნიშვნელობის მისამართი და aux.

<span style="color:red">**!!! არ გაქვთ უფლება Vector-ის ცვლადების პირდაპირ გამოყენების, უნდა გამოიყენოთ მხოლოდ ვექტორის მეთოდები. !!!**</span>

უკვე იმპლემენტირებულ Vector-ს აქვს შემდეგი მეთოდები:

* void VectorInit(Vector* v, int elem\_size) - ინიციალიზაციას უკეთებს გადმოცემულ ვექტორს, elem\_size აღნიშნავს შესანახი ელემენტების ზომას ბაიტებში.
* void VectorDestroy(Vector* v) - ათავისუფლებს ვექტორის მიერ გამოყენებულ მეხსიერებას.
* void VectorAppend(Vector* v, void* elem) - ვექტორის ბოლოს ამატებს გადმოცემულ ახალ ელემენტს. არ იღებს გადმოცემულ მეხსიერებაზე მფლობელობას.
* void VectorRemove(Vector* v, int index) - ვექტორიდან აგდებს მოცემული ინდექსის მქონდე ელემენტს.
* void VectorMap(Vector* v, MapFn map\_fn, void* aux) - ვექტორის ყოველი ელემენტისთვის, დაწყებული 0 ინდექსიდან, იძახებს გადმოცემულ map\_fn ფუნქციას და არგუმენტებად გადასცემს მიმდინარე ელემენტის მისამართს და aux ცვლადს.

<span style="color:red">**!!! არ გაქვთ უფლება Vector-ის ცვლადების პირდაპირ გამოყენების, უნდა გამოიყენოთ მხოლოდ ვექტორის მეთოდები. !!!**</span>


**MapRemove შეფასდება საკითხის შეფასების 20%-ით, ხოლო MapMap 10%-ით.**
