# Ski (ასემბლი - 50 ქულა)
თქვენი ამოცანაა `ski.c` ფაილში არსებული C პროგრამირების ენაზე დაწერილი კოდი გადათარგმნოთ კურსზე გავლილ მანქანურ/ასემბლი კოდში.
თარგმანი ჩაწერეთ `ski.s` ფაილში, სადაც უკვე მონიშნულია თუ სად უნდა დაწეროთ თარგმნილი კოდი. ჯამში სათარგმნი გექნებათ ორი ფუნქცია: `off_piste` და `start_skiing`

**ფუნქციის გამოძახება მასზე მიმთითებლის გამოყენებით შეგიძლიათ გააკეთოთ `jalr` ინსტრუქციის გამოყენებით. მაგალითად ფუნქციის მისამართი ჯერ ჩაწერეთ `a0` რეგისტრში, ხოლო შემდეგ `jalr a0` გამოიძახებს ამ ფუნქციას.**

თარგმნისას გაითვალისწინეთ რომ ქონვენშენების დაცვა საჭიროა როდესაც თქვენი კოდი იძახებს სხვა ფუნქციას ან თქვენს კოდს გამოიძახებენ სხვა ფუნქციიდან. წინააღმდეგ შემთხვევაში ტესტები ჩაგეჭრებათ.
ქონვენშენები რომლებიც უნდა დაიცვათ:
* ფუნქციის არგუმენტების სტეკზე ჩაწერა: ფუნქციის გამოძახებისას **sp** მისამართიდან **0** ოფსეტზე უნდა იწყებოდეს ფუნქციის არგუმენტები. ყველაზე მარცხენა არგუმენტი ჩაწერეთ ყველაზე ნაკლები ოფსეტის მისამართზე. მაგალითი: void fn(int arg0, int arg1) სტეკი: arg0: **sp**, arg1: **sp**+4... თქვენს დასაწერ ფუნქციაშიც არგუმენტები ასეთი მიმდევრობით დაგხვდებათ ჩაწერილი სტეკში.
* თქვენ მიერ დაწერილი ფუნქციებიდან დარეთარნდით, არ გამოიძახოთ exit().
* ფუნქციების return value შეინახეთ **x10** (იგივე **a0**) რეგისტრში. (ჩვენი ფუნქციის გამოძახება თუ დაგჭირდებათ ისიც **x10**-ში ჩაწერს return value-ს)
* ნებისმიერი ფუნქციის გამოძახებამ შეიძლება რეგისტრები გააფუჭოს ანუ გადააწეროს ახალი მნიშვნელობები.
* სტრუქტურის field-ები მეხსიერებაში მიმდევრობითაა განლაგებული და გამოცდაზე შეგიძლიათ ჩათვალოთ, რომ მათ შორის padding-ები არ არის ანუ struct {short a, int b} არის ზუსტად 6 ზომის სტრუქტურა, სადაც a არის შენახული addr+0ზე და b addr+2ზე.

* არ აქვს მნიშვნელობა ლოკალური ცვლადებისთვის რა თანმიმდევრობით გამოყოფთ სტეკში მეხსიერებას.
* აუცილებლად დაგჭირდებათ **ra** რეგისტრის დაბექაფება როდესაც თქვენი დაწერილი ფუნქცია იძახებს სხვა ფუნქციას. დაბექაფების სტრატეგიის არჩევანში თავისუფალი ხართ, მთავარია ზემოთ ჩამოთვლილი ყველა სხვა ქონვენშენი იქნას დაცული. თუმცა ჩვენი რჩევაა ფუნქციის დასაწყისშივე (ლოკალურ ცვლადებთან ერთად) **ra** ბექაფისთვისაც გამოყოთ ადგილი (დამატებით 4 ბაიტი). არ დაგავიწყდეთ რომ **ra** რეგისტრის მნიშვნელობა ფუნქციიდან უკან დაბრუნებამდე აღადგინოთ.

**თუ თქვენი ამოხსნა ტესტებს გადის, ყველაფერი სწორია. `off_piste` ფუნქცია შეადგეს საბოლოო შეფასების 30%-ს, ხოლო `start_skiing` ფუნქცია 70%-ს**
