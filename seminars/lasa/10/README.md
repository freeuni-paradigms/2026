# packed_vector (ჯენერიკები - 60 ქულა)
თქვენი ამოცანაა იმპლემენტაცია გაუკეთოთ PackedVector ჯენერიკ სტრუქტურას, რომელსაც უნდა შეეძლოს განსხვავებული ზომის ელემენტების შენახვა.

PackedVector სტრუქტურას უნდა ქონდეს შემდეგი მეთოდები:

* void VectorInit(Vector\* v); - ინიციალიზაცია უნდა გაუეკთოს მოცემულ ვექტორს.
* void VectorDestroy(Vector\* v); - უნდა გაათავისუფლოს ვექტორის მიერ გამოყენებული დინამიური მეხსიერება.
* void VectorInsert(Vector\* v, int index, int elem\_size, void\* elem, FreeFn free\_fn); - მოცემულ ინდექსზე უნდა ჩაამატოს elem\_size ზომის (ბაიტებში) ელემენტი რომელიც ინახება elem მისამართზე, ხოლო free\_fn ფუნქცია უნდა შეინახოთ და მომავალში გამოიყენოთ ამ ელემენტის მეხსიერების გასათავისუფლებლად (როცა ამის საჭიროება დადგება). გარანტირებული ხართ რომ elem\_size > 0. ახალი ელემენტის ჩამატებამდე მოცემულ ინდექსზე და მის მარჯვნივ მყოფი ყველა ელემენტი უნდა ჩაჩოჩდეს მარჯვნივ.
* void VectorRemove(Vector\* v, int index); - მოცემული ინდექსის ელემენტი უნდა ამოაგდოს სიიდან. მის მარჯვნივ მყოფი ყველა ელემენტი უნდა ჩამოცოცდეს მარცხნივ.
* void\* VectorGet(Vector\* v, int index, int\* elem\_size); - უკან უნდა დააბრუნოს მოცემულ ინდექსზე შენახული ელემენტის მისამართი, ხოლო elem\_size ცვლადში უნდა ჩაწეროს ამ ელემენტის ზომა ბაიტებში.
* void VectorRotate(Vector\* v, int index); - უნდა მოაბრუნოს ვექტორი მოცემულ ინდექსზე.  მობრუნებამდე index პოზიციაზე მყოფი უნდა აღმოჩნდეს 0 პოზიციაზე მობრუნების შემდეგ, index+1 უნდა აღმოჩნდეს 1 პოზიციაზე, ...,  0-ოვანი უნდა აღმოჩნდეს n-index პოზიციაზე, ..., სადაც n განსაზღვრავს ვექტორში შენახული ელემენტების რაოდენობას.
* void VectorMap(Vector\* v, MapFn map\_fn, void\* aux); - ვექტორში შენახული ყველა ელემენტისთვის უნდა გამოიძახოს გადმოცემული map\_fn ფუნქცია, რომელსაც არგუმენტებად უნდა გადასცეს: მიმდინარე ელემენტის ინდექსი, ამ ელემენტის ზომა ბაიტებში, ამ ელემენტის მნიშვნელობის მისამართი, და VectorMap-ისთვის კლიენტის მიერ გადმოცემული aux მნიშვნელობა.

იმის და მიხედვით თუ როგორ ამოხსნას დაწერთ ნამუშავარში აიღებთ:
* 100% - არ უნდა აღწეროთ დამხმარე struct-ები, Vector-ში არ უნდა ინახავდეთ ერთზე მეტ დინამიურად გამოყოფილ მეხსიერებაზე მისამართს.
* 80% - თუ ზედა მოთხოვნას დაარღვევთ.


**ტესტების 50%-ში ვექტორში შენახული ყველა ელემენტს ერთი ზომა ექნება ბაიტებში და ჩამატების ფუნქციისთვის გადაცემული free_fn არგუმენტი იქნება NULL.**

**VectorRotate შეფასდება საკითხის შეფასების 10%-ით, ხოლო VectorMap 10%-ით.**

**მეხსიერების არასწორად გამოყენების შემთხვევაში დაკარგავთ ტესტისთვის განკუთვნილი ქულის 15%-ს.**

**ნაკლები შეცდომები რომ დაუშვათ და კოდიც უფრო პატარა გამოგივიდეთ, გირჩევთ გამეორებადი ლოგიკა გაიტანოთ დამხმარე ფუნქციებად ან აღწეროთ მაკროების (define) გამოიყენოთ.**
