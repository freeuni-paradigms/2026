# Max2Bit (30 ქულა)

თქვენი ამოცანაა იმპლემენტაცია გაუკეთეოთ FindMax ფუნქციას, რომელმაც მოცემულ რიცხვებს შორის უნდა იპოვოს პირველი მაქსიმალური და დააბრუნოს მისი პოზიცია.  
მოცემული რიცხვები შედგებიან მხოლოდ ორი ბიტისაგან, შესაბამისად მეხსიერების დაზოგვის მიზნით ერთ ბაიტში ინახება ოთხი რიცხვი. მაგალითად 00100100 (ათობითში 36) ასახავს შემდეგ ოთხ რიცხვს 0 (00), 2 (10), 1 (01) და 0 (00).

FindMax ფუქნციას გადაეცემა ბაიტების მიმდევრობა void\* -ის სახით და ბოლოვდება 0-ით (ანუ 00000000 ბაიტით). უკან უნდა დააბრუნოს მოცემულ ბაიტებში შენახულ ორ ბიტიან რიცხვებს შორის მაქსიმალურის პოზიცია. თუ მაქსიმალური რიცხვი რამოდენიმეჯერ გვხვდება, მაშინ უნდა დააბრუნოს პირველის ანუ ყველაზე მარცხენას პოზიცია. რიცხვები გადანომრილია მარცხნიდან მარჯვნივ და გადანომვრა იწყება 0-იდან.

გარანტირებული ხართ რომ გადმოცემული void\* მისამართი არანულოვანია.

გარანტირებული ხართ რომ შემოსული რიცხვების რაოდენობა 4-ის ჯერადია. ანუ ბოლო ბაიტის გარდა სადაც 0 წერია ყველა ბაიტში 4-4 რიცხვია შენახული.

მაგალითად თუ მეხსიერებაში წერია `00110111 00000000` -> ეს ნიშნავს რომ გვაქვს რიცხვები `0 3 1 3` და პასუხად უნდა დაბრუნდეს ყველაზე მარცხენა მაქსიმალური რიცხვის `3`ის ინდექსი, რომელიც არის `1`
